# ColorCraft - 1 Page Business Website

A simple and responsive one-page business website for a painting and wall texture service.

## About The Project

This project is a simple business landing page created for a fictional painting and wall texture company called ColorCraft.

The website presents the company's services, basic information, contact details, and a simple contact form.

The project was created as a Front-End Web Development practice project based on a real-world Upwork job example.

## Features

- Responsive design
- One-page layout
- Navigation bar
- Hero section
- About section
- Services section
- Why Choose Us section
- Contact section
- Simple contact form validation
- Mobile-friendly layout

## Technologies Used

- HTML5
- CSS3
- Bootstrap 5
- JavaScript
